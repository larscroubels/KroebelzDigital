# Kroebelz Digital website

A responsive one-page portfolio website for Kroebelz Digital, built with HTML, CSS, JavaScript and Bootstrap 5.

## Run it
Open `index.html` in a browser. Bootstrap and Google Fonts are loaded from online CDNs, so an internet connection is needed for those resources.

## Contact form
The contact form validates the fields and opens the visitor's default email app with the details filled in. It does not send messages directly or store submissions. To receive form submissions without requiring the visitor's email app, connect a form service or add a backend.

## Main files
- `index.html` — page content and Bootstrap structure
- `css/style.css` — brand styling and responsive layouts
- `js/main.js` — mobile navigation, footer year and contact form behaviour
- `assets/` — supplied Kroebelz Digital logos and portrait

## Brand colours
- Deep red: `#a20f1b`
- Black: `#090909`
